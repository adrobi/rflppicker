# Совместное проектирование ПЦР-ПДРФ: модель v1

Версия модели: `band-presence-maximin-v1`. Это воспроизводимая эвристика
вычислительного отбора, а не заявление о новом методе или экспериментально
доказанной точности генотипирования.

## Поиск

Для каждого SNP Primer3 возвращает до K пар (по умолчанию 10, максимум 100).
Проверяются координаты, последовательности, размер продукта и расположение
SNP строго между праймерами. Дубликаты пар удаляются. Для каждого полученного
ампликона рассчитывается полная рестрикция REF и ALT каждым выбранным ферментом.
Ограничение на число разрезов применяется отдельно к обоим аллелям.
Ошибка расчёта фермента исключает сочетание и учитывается в отчёте; она
не означает отсутствие сайтов. Ампликоны с основаниями вне A/C/G/T пропускаются.
Фермент, ни один сайт которого не перекрывает SNP ни в REF, ни в ALT, режет
оба аллеля любого ампликона одинаково (Δ = 0). Поэтому с версии 1.2 такие
ферменты отсеиваются один раз на SNP, до перебора пар; результаты совпадают
с полным перебором (`tools/regression.py`).

Поиск исчерпывающий только среди возвращённых K пар и выбранных ферментов:
это не глобальная оптимизация всех возможных праймеров. Primer3 упорядочивает
пары по своей оценке, поэтому увеличение K расширяет проверяемый набор,
но не гарантирует разнообразия длин ампликонов.

## Математическая модель различимости

1. Фрагменты вне `[min_frag, max_frag]` считаются невидимыми. Их количество
   сохраняется отдельно. Совпадающие длины дают одну полосу, без оценки яркости.
2. Для двух длин a и b задаётся расстояние в единицах разрешения:

   `d_s(a,b) = |a-b| / (s × max(r_bp, r_pct × max(a,b) / 100))`.

   Здесь `r_bp > 0`, `r_pct ≥ 0`, а `s` — коэффициент ухудшения разрешения.
   Это явно заданная модель, не универсальная физическая калибровка геля.
3. Общий отсортированный набор видимых длин обоих аллелей разбивается на
   компоненты: соседние длины с `d_s ≤ 1` объединяются транзитивно. Это
   консервативное правило: цепочка близких полос рассматривается как один
   неразрешимый диапазон. Одни и те же компоненты используются во всех дорожках;
   диапазон, например `100–118`, не является доверительным интервалом.
4. RR содержит компоненты REF, AA — ALT, RA — их объединение. Различение
   трёх генотипов по наличию полос требует хотя бы одной компоненты только REF
   и хотя бы одной компоненты только ALT. Если видимых полос какого-либо аллеля
   нет, оценка равна нулю: отсутствие дорожки не используется как признак генотипа.
5. Для каждой эксклюзивной компоненты REF вычисляется минимальное d_s между
   любой длиной этой компоненты и любой видимой длиной ALT. Максимум этих
   минимумов обозначается U_REF. Аналогично вычисляется U_ALT. При отсутствии
   эксклюзивной компоненты соответствующая оценка равна нулю.

   Оценки пар генотипов:

   - RR / RA: U_ALT;
   - RA / AA: U_REF;
   - RR / AA: max(U_REF, U_ALT).

   Итог: `Q_s = min(U_REF, U_ALT)` — оценка наиболее трудной пары генотипов.
   Значение больше 1 означает различимость только в рамках этой модели;
   это не вероятность, не точность и не экспериментальная гарантия.
6. Рассчитываются Q_1 и Q_S, где S по умолчанию 1.5. При росте s компоненты
   только объединяются, а нормированные расстояния уменьшаются. Поэтому Q_S
   — худшая оценка на всём интервале `[1,S]`, а не результат случайного моделирования.
   В экспорт входят наборы полос и при исходном, и при ухудшенном разрешении.

Пример принципиального ограничения старого фильтра: REF `100+200`, ALT
`100+100+100`. Гомозиготы имеют разные наборы полос, но RA и RR совпадают
по присутствию полос. Оценка трёх генотипов равна нулю независимо от яркости.

## Отбор и ранжирование

Сохраняется фильтр Δ: симметричное расстояние Хаусдорфа в п.н. между
видимыми длинами REF и ALT должно быть не меньше заданного порога.
В совместном режиме дополнительно требуется Q_1 > 1.

Кандидаты одного SNP упорядочиваются лексикографически:

1. Q_S по убыванию;
2. Q_1 по убыванию;
3. штраф пары Primer3 по возрастанию (отсутствующий штраф — последним);
4. количество полос гетерозиготы по возрастанию;
5. имя фермента и исходный номер пары для воспроизводимого разрешения равенств.

Произвольной взвешенной суммы критериев нет. Первые N строк выдаются на SNP;
N=0 сохраняет все. `candidates` в отчёте — число до усечения.
`assay_rank` относится только к конкретному SNP, не ко всему файлу.

Качество: `robust` — Q_S > 1; `nominal_only` — только Q_1 > 1;
`ambiguous` — Q_1 ≤ 1. Последний статус может присутствовать в режиме
одной пары или окна, но не среди кандидатов совместного поиска.

## Отбор и проверки (с версии 1.2)

Все проверки ниже выключены в `rflp_core.DEFAULT_PARAMS`, поэтому набор
параметров v1.1.0 даёт прежние строки (новые столбцы добавляются в конец).
Окно программы и `rflp_cli.py` по умолчанию используют
`RECOMMENDED_PARAMS` — настройки, выбранные по итогам проверки на
опубликованных анализах.

- **Только продаваемые ферменты** (`commercial_only`): ферменты, для которых
  в REBASE указан хотя бы один поставщик (623 из 1088 в Biopython 1.88).
- **Изошизомеры в одной строке** (`group_isoschizomers`): для каждого SNP
  остаётся одна схема на сайт узнавания. Сайт представляет продаваемый фермент,
  если такой есть (неошизомер, режущий на основание дальше, может получить
  чуть большую оценку), затем лучшая оценка, затем число поставщиков.
  Остальные ферменты сайта перечисляются в столбце `isoschizomers`; лимит
  результатов применяется после объединения, а `candidates` в отчёте
  считается до него (`candidate_sites` — число различных сайтов). В проверке
  v1.1.0 опубликованный фермент без объединения часто оттеснялся вниз
  собственными изошизомерами (CYP19/DpnII: 293-е место по ферментам, 17-е по сайтам).
- **SNP не ближе d п.н. к концам ампликона** (`snp_end_distance`, рекомендуется
  100). Primer3 получает цель `[snp − k, snp + k]`, `k = d − 18`: праймеры
  лежат вне цели, а минимальная длина праймера задаётся явно (18), поэтому
  от SNP до каждого конца не меньше d оснований; это дополнительно
  проверяется для каждой пары (`pairs_near_end` в отчёте). Диагностический
  разрез лежит в сайте, перекрывающем SNP, поэтому иначе один из фрагментов
  оказывается короче видимого порога. В проверке v1.1.0 так был пропущен
  HOXB13/BsrI: все 10 пар ставили SNP в 18–22 п.н. от края. С d = 100 сайт
  BsrI находится, с рекомендуемыми настройками — на первом месте (Q₁ = 15.8).
  Значение должно быть не меньше `min_frag`. Ограничение не действует в поиске
  по окну; если окно короче, SNP получает статус `no_primers` с пояснением.
- **Сайт фермента в праймере** (`primer_site`, исключение —
  `exclude_primer_sites`). Отмечается праймер, целиком содержащий сайт
  выбранного фермента (поиск по продукту, то есть по последовательности праймера
  в том виде, в каком он входит в ампликон). Такой сайт есть в продукте при любом
  аллеле, а разрез у самого конца ДНК идёт ненадёжно: неполное расщепление даёт
  лишнюю полосу, сдвинутую на длину праймера. В проверке v1.1.0 напечатанный
  праймер ygl19 сам содержал сайт TaqI, и по расчёту резался любой аллель.
  Длины фрагментов такой сайт уже учитывали; меняется только отбор.
- **Повторы** (`mask_repeats`). Геномы NCBI и Ensembl (`dna_sm`) отмечают
  повторы строчными буквами (soft-mask): в ARS-UI_Ramb_v2.0 и IRGSP-1.0 из
  RefSeq это около трети оснований. v1.1.0 переводила окно в верхний регистр
  до Primer3; теперь Primer3 получает окно с регистром и
  `PRIMER_LOWERCASE_MASKING=1`, то есть 3′-конец праймера не попадает в повтор.
  Остальные расчёты по-прежнему выполняются в верхнем регистре. Доля
  оснований повторов в ампликоне — столбец `repeat_pct`. Если в окнах нет ни
  одной строчной буквы, журнал предупреждает, что FASTA без soft-mask.
  Специфичность праймеров по всему геному по-прежнему не проверяется.
- **Фоновые варианты** (`background_vcf`, исключение — `exclude_background_sites`).
  VCF или VCF.gz известных вариантов (например, породы или популяции) читается
  один раз потоком; сохраняются только записи в окнах входных SNP. Названия
  хромосом VCF переводятся тем же файлом соответствий, что и входные SNP.
  Запись самого SNP и записи, REF которых не совпадает с FASTA
  (`background_ref_mismatch`: обычно VCF другой сборки), не используются.
  Primer3 не ставит праймеры на известные варианты (`SEQUENCE_EXCLUDED_REGION`).
  Для каждой схемы `background_variants` — число известных вариантов в
  ампликоне, `background_site_variants` — те из них, что могут изменить
  результат: замена — если меняет набор сайтов фермента, покрывающих её
  (точно, при обоих аллелях SNP); индел — если касается сайта или сдвигает
  длину на величину не меньше разрешения геля. В проверке v1.1.0 два
  расхождения (CYP2E1/AciI, HOXB13/BsrI) объяснялись именно соседней заменой,
  создающей дополнительный сайт. Пример: VCF овцы на 15,2 млн записей (2,2 ГБ)
  читается примерно за 10 с.
- **dCAPS / forced-RFLP** (`dcaps`: `off`, `fallback` — только для SNP без
  robust-схемы с природным сайтом, `always`; `dcaps_mismatches`: 1–2).
  Праймер упирается 3′-концом в SNP (левый заканчивается перед ним, правый
  садится сразу после). Перебираются положения сайта, покрывающие SNP:
  основания сайта со стороны праймера можно заменить (не более
  `dcaps_mismatches`, никогда — концевое 3′-основание), основания по другую
  сторону SNP берутся из генома без изменений, а в позиции SNP сайт должен
  допускать ровно один аллель. Длина праймера — наибольшая (18–36 нт) с Tm в
  заданном диапазоне: чем длиннее праймер, тем дальше разрез от конца продукта
  и тем больше диагностическое различие. Праймер не ставится на известные
  варианты, а при `mask_repeats` его 3′-конец не попадает в повтор. Второй
  праймер подбирает Primer3 по шаблону с внесёнными заменами
  (`SEQUENCE_PRIMER`/`SEQUENCE_PRIMER_REVCOMP`). Продукт режется Biopython
  по последовательности с несовпадением, и дальше действуют те же фильтры
  (число разрезов, Δ, модель полос), что для природных сайтов; схема, где праймер
  с несовпадением сам содержит сайт фермента, отбрасывается всегда. Ферменты с
  неизвестным местом разреза не используются. Испытывается до 40 вариантов
  праймера на SNP (сначала с меньшим числом замен). В таблице: `design` =
  `dCAPS`, замены в праймере — строчными буквами, `primer_mismatches` —
  например `right 3'-2 G>C` (второе основание от 3′-конца правого праймера).
  Различие полос примерно равно длине праймера, поэтому нужны короткие продукты
  и тонкое разрешение; при пороге Δ = 25 п.н. многие схемы отсекаются.
  Проверка на пяти опубликованных forced-RFLP (параметры статьи, Δ = 15,
  dCAPS для каждого SNP): найдены BMP15/HinfI (6-е место) и SD1/MseI (2-е,
  изошизомер Tru9I). GE/MseI находится только при диапазоне продукта
  150–1000 п.н. (8-е место): опубликованные forced-RFLP продукты короче
  250 п.н. (128–176). ygl19/TaqI отвергается правильно —
  опубликованный праймер содержит природный сайт TaqI, и режется любой аллель.
  Wx/BseNI — природный сайт, где несовпадения лишь убирают соседние сайты в
  праймере; такие схемы не проектируются.
- **Виртуальный гель** — вкладка окна визуализации: маркер 50–2000 п.н.,
  продукт без фермента и дорожки REF/REF, REF/ALT, ALT/ALT. Подвижность
  линейна по логарифму длины, яркость пропорциональна массе фрагмента
  (у гетерозиготы — по половине каждого аллеля); фрагменты вне видимого
  диапазона модели бледные и в скобках. Это иллюстрация той же модели полос,
  а не имитация конкретного геля. Сохраняется в PNG и SVG.

Метрика 3 проверки 1.1.0 (найдена ли опубликованная схема только по
координате и аллелям; параметры статьи, K = 10, для эквивалентных позиций
засчитывается худший результат, изошизомер считается найденным ферментом):

| | природные сайты (12): найдены | в первой десятке сайтов | на 1-м месте | forced-RFLP (5) |
|---|---|---|---|---|
| параметры 1.1.0 | 9 | 8 | 3 | 0 |
| 1.2, настройки по умолчанию | 10 | 10 | 5 | 0 |
| 1.2 + dCAPS для каждого SNP, Δ = 15 | 10 | 10 | 5 | 2 |

Первая строка воспроизводит результат статьи. Добавился HOXB13/BsrI (1-е

поисковая оценка на тех же 17 анализах, по которым выбирались изменения, а не
независимая проверка.

## Совместимость и воспроизводимое сравнение

При отключении совместного поиска выбирается первая пара Primer3 и сохраняется
старое требование: каждый фрагмент должен попадать в заданный диапазон.
При отключении Primer3 анализируется окно; результат явно обозначен как
`window_only`, он не является готовой схемой ПЦР.

Команда сравнения (из каталога проекта):

```powershell
python benchmark_design.py --fasta genome.fa --variants variants.tsv --pairs 10 --output results/experiment_01
```

При необходимости добавьте `--names names/ARS-UI_Ramb_v2.0.txt` и параметры
длин, Tm и модели геля (`--help`). Каталог вывода должен быть новым.
Сравниваются `legacy_single`, `joint_one` и `joint_many`:

- `legacy_single` против `joint_one` показывает изменение правил отбора;
- `joint_one` против `joint_many` позволяет отдельно оценить расширение поиска пар.

Все режимы получают одинаковые входные SNP и параметры оценки. CSV содержит
все кандидаты, сводка — число SNP с различимыми и устойчивыми схемами,
число пар, время и ошибки. JSON сохраняет параметры, версии библиотек,
контрольные суммы входных файлов и расчётного кода. Хеширование большого
FASTA может занять время; оно не включено во время отдельных режимов.
Однократное время зависит от кэша и порядка запусков. Для статьи нужны
повторные измерения с изменением порядка, характеристики оборудования,
реальные открытые или разрешённые к использованию данные и анализ
чувствительности к K и параметрам разрешения.

Для проверки установки имеются **синтетические** данные:

```powershell
python examples/generate_demo.py
python benchmark_design.py --fasta examples/synthetic.fa --variants examples/synthetic.tsv --output results/demo_01
```

Эти данные пригодны для проверки работоспособности, не для выводов о
биологической эффективности и не заменяют независимую валидацию.

## Ограничения

Предполагается диплоидный биаллельный SNP, полная рестрикция и успешная
амплификация обоих аллелей. Не моделируются интенсивность/детектируемость полос,
неполная рестрикция, метилирование, неспецифическая активность фермента и
аллельное выпадение; фоновые полиморфизмы учитываются только из переданного
VCF. Специфичность праймеров по всему геному не проверяется; влияние
несовпадения праймера dCAPS на эффективность ПЦР не оценивается. Требуются проверка существующих аналогов и
экспериментальная калибровка, прежде чем заявлять научную новизну или
лабораторную надёжность.

Первичный источник параметров и координат Primer3:
[официальное руководство](https://primer3.org/manual.html).
Расчёт сайтов выполняет Biopython; собственный вклад этой версии —
совместный перебор кандидатов, модель полос и проверяемое правило ранжирования.
