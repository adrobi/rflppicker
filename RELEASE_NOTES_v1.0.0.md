# RFLP Picker v1.0.0

Первый Windows-релиз программы для поиска RFLP-маркеров и подбора PCR-праймеров.

## Что вошло

- анализ одиночных SNP по референсному FASTA;
- поиск рестриктаз для различения REF и ALT;
- подбор праймеров через Primer3;
- явные статусы: найденные праймеры, отсутствие пары, ошибка Primer3 и отсутствие фермента;
- проверка координат и соответствия REF референсному геному;
- фильтрация и числовая сортировка результатов;
- визуализация REF/ALT с масштабированием и экспортом PNG/SVG;
- экспорт результатов в безопасные CSV и Excel с листами `Results`, `Run` и `Rejected`;
- автоматическая поддержка светлой и тёмной темы Windows;
- тестовый набор из 14 проверок и GitHub Actions для CI.

## Ограничения

- поддерживаются одиночные SNP A/C/G/T;
- референсный FASTA не включён в архив: локальный файл `ARS-UI_Ramb_v2.0.fa`
  занимает около 2.66 ГБ;
- перед анализом укажите полный путь к FASTA и, при необходимости, к файлу
  соответствий названий хромосом.

## Быстрый старт

1. Распакуйте архив.
2. Запустите `RFLP-Picker.exe`.
3. Выберите CSV/TSV с колонками `chrom`, `pos`, `ref`, `alt`.
4. Укажите путь к референсному FASTA.
5. Запустите анализ и выберите строку результата для просмотра схемы.
